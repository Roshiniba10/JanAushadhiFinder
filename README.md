# Jan Aushadhi Finder 

Jan Aushadhi Finder is an Android application that helps users locate nearby **Pradhan Mantri Bhartiya Janaushadhi Kendras (PMBJK)** and search for affordable generic medicines easily.

## Features

-  Search medicines quickly
-  Find nearby Jan Aushadhi stores
-  View medicine details
-  Google Maps integration
-  User-friendly Android interface
-  Firebase integration

---

##  Tech Stack

- Android Studio
- Java / Kotlin
- Firebase

- XML

##  Installation

### 1️ Clone the Repository

```bash
git clone https://github.com/Roshiniba10/JanAushadhiFinder.git
```

### 2️ Open in Android Studio

- Open Android Studio
- Click **Open**
- Select the project folder

### 3️ Add Firebase File

Place your `google-services.json` file inside:

```bash
app/google-services.json
```

### 4️ Sync Gradle & Run

- Sync Gradle files
- Run the app on emulator or device

---

##  Firebase Setup

1. Open Firebase Console
2. Create a Firebase Project
3. Add Android App
4. Download `google-services.json`
5. Place it in the `app/` folder
