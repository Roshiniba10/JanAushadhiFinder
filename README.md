# Jan Aushadhi Finder 💊

Jan Aushadhi Finder is an Android application designed to help users quickly locate nearby Jan Aushadhi Kendras and find affordable generic medicines easily.

## 📌 Features

- 🔍 Search Jan Aushadhi stores
- 📍 Locate nearby medical shops
- 💊 Find affordable generic medicines
- 🗺️ User-friendly interface
- 📱 Android-based application
- 🔐 Firebase integration

## 🛠️ Technologies Used

- Java / Kotlin
- Android Studio
- Firebase
- Google Maps API
- XML
